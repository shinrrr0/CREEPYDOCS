# Fonts directory

The display font for the title — **"another danger"** — is loaded locally.
Drop the file here as `another-danger.woff2` (preferred) or
`another-danger.ttf` and the existing `@font-face` block in
`static/css/fonts.css` will pick it up automatically.

If the file is missing, the title falls back to `Creepster` /
`Impact` so the page is still readable during development.
